Politique de confidentialité — HexaLexique

Version 1.0 · Bêta fermée · 2026-06-29
Package Android : com.olasserre.hexalexique

1. Préambule

HexaLexique est un jeu de mots roguelite pour Android, distribué en bêta fermée sur Google Play.

Éditeur : Olivier Lasserre
Contact : o.lasserre@gmail.com
Version : 0.1.0 (bêta fermée)

Cette politique de confidentialité décrit précisément quelles données HexaLexique traite, où elles sont stockées, et ce qui n'est pas collecté.

2. Principe fondamental — Offline-first

HexaLexique est conçu pour fonctionner entièrement hors ligne. Aucune donnée personnelle n'est transmise à un serveur externe. Il n'existe aucun backend, aucun serveur d'analyse, aucune base de données distante associée à cette application.

3. Données traitées localement sur votre appareil

Les informations suivantes sont stockées localement sur votre appareil via AsyncStorage (stockage clé-valeur local d'Android), uniquement pour assurer le fonctionnement du jeu :

3.1 Préférences utilisateur

  • Activation ou désactivation des sons SFX (clic de tuile, confirmation de mot)
  • Activation ou désactivation de la musique ambiante
  • Activation ou désactivation des vibrations (haptique)

Ces préférences ne sont pas transmises hors de l'appareil.

3.2 Sauvegarde de run

  • État de la partie en cours (plateau, reliques actives, étage, score)
  • Style de départ sélectionné (Le Poète, L'Architecte, Le Collectionneur)
  • Graine RNG (seed) de la run en cours

Ces données permettent de reprendre une partie interrompue. Elles restent locales et sont supprimées à la désinstallation ou à la réinitialisation de l'application.

3.3 Métriques locales

  • Record d'étage atteint (highestStageReached) affiché sur l'écran d'accueil

Cette valeur est locale, non partagée, non transmise.

3.4 Export diagnostic volontaire

L'application peut permettre à l'utilisateur d'exporter un fichier JSON de diagnostic. Cet export est une action volontaire de l'utilisateur. Le fichier est produit localement et transmis uniquement si l'utilisateur choisit de le partager manuellement (par e-mail ou autre). HexaLexique n'initie aucun envoi automatique de ce fichier.

4. Données NON collectées

HexaLexique ne collecte, ne transmet et ne stocke hors de l'appareil aucune des données suivantes :

  • Nom, prénom, adresse e-mail ou tout identifiant personnel
  • Localisation géographique
  • Identifiant publicitaire (Google Advertising ID)
  • Données de navigation ou de comportement transmises à des tiers
  • Données de crash transmises automatiquement (aucun SDK de crash reporting dans ce build)
  • Données biométriques
  • Contacts, SMS, appels téléphoniques
  • Photos ou fichiers de l'appareil

5. Microphone — Absence confirmée

La permission RECORD_AUDIO est absente du manifest de cette application. HexaLexique utilise expo-audio pour la lecture audio uniquement (sons SFX et musique ambiante). L'accès au microphone n'est pas requis, pas demandé et pas utilisé.

6. Publicité

HexaLexique ne contient aucune publicité réelle dans cette version bêta. Aucun identifiant publicitaire n'est collecté.

7. Achats intégrés

Il n'existe aucun achat intégré dans cette version. HexaLexique est entièrement gratuit pour les testeurs de la bêta fermée.

8. Services tiers

HexaLexique n'intègre aucun service tiers collectant des données :

  • Pas de Supabase
  • Pas de Firebase / Google Analytics
  • Pas de Sentry ou SDK de crash reporting
  • Pas de SDK publicitaire actif

Les dépendances utilisées (Expo SDK ~56, React Native, expo-audio, expo-haptics, @react-native-async-storage/async-storage) traitent des données uniquement en local sur l'appareil.

10. Durée de conservation des données

Les données traitées localement (préférences, sauvegarde, record) sont conservées sur l'appareil aussi longtemps que l'application est installée. Elles sont supprimées automatiquement à la désinstallation de l'application.

11. Suppression des données

Pour supprimer toutes les données traitées par HexaLexique :

  1. Désinstaller l'application : toutes les données locales sont effacées.
  2. Réinitialiser via les Réglages Android : Paramètres › Applications › HexaLexique › Stockage › Effacer les données.

Aucune procédure de suppression distante n'est nécessaire car aucune donnée n'est transmise hors de l'appareil.

12. Droits des utilisateurs (RGPD)

Dans la mesure où HexaLexique ne traite aucune donnée à caractère personnel au sens du RGPD (les données restent locales sur l'appareil de l'utilisateur et ne sont pas transmises à l'éditeur), les droits d'accès, rectification, portabilité et opposition ne s'appliquent pas de façon standard.

Toute question peut néanmoins être adressée à : o.lasserre@gmail.com
